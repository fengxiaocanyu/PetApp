## 一、皮肤资源（config/skins/）

### 1.1 目录结构

```
config/skins/
├── default/              # 默认皮肤（必须存在）
│   ├── frame_0001.png
│   ├── frame_0002.png
│   ├── ...
│   └── frame_0010.png
├── happy/                # 开心表情（可选）
│   ├── frame_0001.png
│   ├── frame_0002.png
│   └── ...
├── sad/                  # 难过表情（可选）
│   ├── frame_0001.png
│   └── ...
└── custom_skin/          # 自定义皮肤（用户创建）
    ├── frame_0001.png
    ├── frame_0002.png
    └── ...
```

### 1.2 文件规格

| 属性 | 要求 |
|------|------|
| 格式 | PNG（推荐，支持透明背景） |
| 尺寸 | 128×128 像素（推荐，可接受其他尺寸） |
| 背景 | 透明背景（RGBA） |
| 命名规则 | `frame_0001.png`（4 位数字序号，从 0001 开始） |
| 帧数 | 每个皮肤至少 1 帧，推荐 4-10 帧 |
| 帧率 | 程序默认 200ms/帧（可通过代码调整） |

### 1.3 表情映射

AppearanceManager 通过 `setEmotion()` 切换表情目录。程序订阅 `emotion_changed` 事件，根据情感值自动切换：

| 情感状态 | 对应皮肤目录 | 触发条件 |
|----------|-------------|----------|
| 愉悦高 | `happy/` | pleasure > 0.7 |
| 愉悦低 | `sad/` | pleasure < 0.3 |
| 疲倦高 | `tired/` | tiredness > 0.7 |
| 默认 | `default/` | 其他情况 |

### 1.4 示例图片

你可以使用以下方式生成皮肤图片：

**方法 1：手绘/设计**
- 使用 Photoshop、GIMP、Aseprite 等工具绘制
- 导出为 128×128 PNG 透明背景

**方法 2：AI 生成**
- 使用 Stable Diffusion、DALL-E 等生成桌宠形象
- 裁剪为 128×128，导出 PNG

**方法 3：像素画**
- 使用 Piskel (https://www.piskelapp.com/) 在线绘制
- 导出为 PNG sprite sheet 后拆分

## 二、OCR 语言包（data/models/）

### 2.1 目录结构

```
data/models/
├── tessdata/             # Tesseract 语言包目录
│   ├── eng.traineddata   # 英文语言包
│   ├── chi_sim.traineddata  # 简体中文语言包（可选）
│   └── ...
└── tesseract.exe         # Tesseract OCR 可执行文件（可选，也可放系统 PATH）
```

### 2.2 文件规格

| 文件 | 来源 | 说明 |
|------|------|------|
| `tesseract.exe` | https://github.com/UB-Mannheim/tesseract/wiki | 下载 Windows 安装包，提取 exe |
| `eng.traineddata` | https://github.com/tesseract-ocr/tessdata | 英文语言包，约 4MB |
| `chi_sim.traineddata` | https://github.com/tesseract-ocr/tessdata | 简体中文，约 50MB |

### 2.3 安装步骤

1. 下载 Tesseract Windows 安装包（推荐 5.x 版本）
2. 安装后从安装目录复制 `tesseract.exe` 到 `data/models/`
3. 从 tessdata 仓库下载语言包到 `data/models/tessdata/`
4. 确保 skill_ocr 能找到 tesseract（优先查找 `data/models/tesseract.exe`，其次系统 PATH）

## 三、翻译词典（skills/skill_translate/）

### 3.1 文件位置

```
skills/skill_translate/
├── main.cpp              # 已存在
├── manifest.json         # 已存在
└── dictionary.json       # 需要用户创建（可选，默认使用内置小词典）
```

### 3.2 dictionary.json 格式

```json
{
  "version": "1.0",
  "language": "en-zh",
  "entries": [
    {
      "word": "hello",
      "translation": "你好",
      "pos": "interjection"
    },
    {
      "word": "world",
      "translation": "世界",
      "pos": "noun"
    },
    {
      "word": "computer",
      "translation": "计算机",
      "pos": "noun"
    },
    {
      "word": "translate",
      "translation": "翻译",
      "pos": "verb"
    }
  ]
}
```

### 3.3 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| word | string | 是 | 英文单词（小写） |
| translation | string | 是 | 中文翻译 |
| pos | string | 否 | 词性（noun/verb/adjective/adverb/interjection） |

### 3.4 词典来源

- 开源词典：https://github.com/skywind3000/ECDICT（英语-中文词典，约 3.5M 词条）
- 转换工具：可使用 Python 脚本将 ECDICT 的 CSV 格式转换为 JSON

## 四、技能市场 API 服务端

### 4.1 接口规范

技能市场对话框请求的 API 地址在 `src/ui/SkillMarketDialog.cpp` 中硬编码：

```cpp
// 第 153 行附近
QUrl apiUrl("https://api.petapp.dev/skills/list");
```

### 4.2 修改方式

**方式 A：部署自己的服务端**

实现一个 REST API：

```
GET /skills/list
Response: [
  {
    "id": "com.example.my_skill",
    "name": "我的技能",
    "version": "1.0.0",
    "description": "技能描述",
    "requires_network": false,
    "resource_weight": 1,
    "download_url": "https://example.com/skills/my_skill.zip"
  }
]
```

**方式 B：修改源码中的 URL**

编辑 `src/ui/SkillMarketDialog.cpp`，将 URL 改为你的服务端地址：

```cpp
QUrl apiUrl("https://your-server.com/api/skills");
```

## 七、验证步骤

提交所有文件后，按以下步骤验证：

### 7.1 皮肤验证

1. 启动 PetApp.exe
2. 点击 ⚙️ 设置
3. 在皮肤选择下拉框中应看到 `default` 选项
4. 选择后桌宠形象应显示为你的皮肤图片

### 7.2 OCR 验证

1. 准备一张包含英文文字的图片（如 screenshot.png）
2. 确保 `data/models/tesseract.exe` 和 `data/models/tessdata/eng.traineddata` 存在
3. 运行 skill_ocr 测试：
   ```cmd
   echo {"method":"execute","id":1,"params":{"input":"C:\\path\\to\\screenshot.png","config":{}}} | plugins\skill_ocr.exe
   ```

### 7.3 翻译验证

1. 如果提供了 dictionary.json，运行 skill_translate 测试：
   ```cmd
   echo {"method":"execute","id":1,"params":{"input":"hello","config":{"src_lang":"en","tgt_lang":"zh"}}} | plugins\skill_translate.exe
   ```
2. 应输出：`{"id":1,"result":"你好","error":null}`

### 7.4 打包验证

1. 运行 `scripts\package.ps1`
2. 将生成的 ZIP 包解压到另一台 Windows 电脑
3. 双击 `run.bat` 启动 PetApp.exe，确认无需额外安装即可运行
4. 测试所有技能按钮和设置功能

> **注意**：不要直接双击 PetApp.exe，因为 Windows 可能将工作目录设置为其他位置，导致找不到 plugins/、config/ 等资源目录。请使用 run.bat 或从命令行 `cd` 到解压目录后运行。
