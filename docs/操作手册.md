# PetApp 桌宠系统 - 操作手册

## 一、编译与运行

### 1.1 前置条件

| 软件 | 版本要求 | 安装路径（参考） |
|------|---------|-----------------|
| Visual Studio 2022 | 17.x+ | D:\software\work\VS2022 |
| CMake | 3.22+ | VS2022 自带 |
| Ninja | 1.10+ | VS2022 自带 |
| Qt | 6.8.3 (msvc2022_64) | E:\work\QT\6.8.3\msvc2022_64 |

### 1.2 编译步骤

**步骤 1：打开开发者命令提示符**

```cmd
call "D:\software\work\VS2022\Common7\Tools\VsDevCmd.bat" -arch=x64 -host_arch=x64
```

**步骤 2：配置项目**

```cmd
cd D:\github\work\PetApp
cmake -B build -G Ninja -DCMAKE_PREFIX_PATH="E:/work/QT/6.8.3/msvc2022_64"
```

**步骤 3：编译**

```cmd
cmake --build build
```

**步骤 4：运行**

```cmd
.\PetApp.exe
```

### 1.3 编译选项

| 选项 | 说明 |
|------|------|
| Debug | 默认，带调试信息 |
| Release | 优化版本，用于发布 |

编译 Release 版本：

```cmd
cmake -B build_release -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="E:/work/QT/6.8.3/msvc2022_64"
cmake --build build_release
```

> **注意**：Ninja 是单配置生成器，`--config Release` 参数对 Ninja 无效。若使用 Visual Studio 生成器（`-G "Visual Studio 17 2022"`），则需添加 `--config Release`。

### 1.4 清理重建

```cmd
cmake --build build --clean-first
```

或删除 build 目录后重新配置：

```cmd
rmdir /s /q build
cmake -B build -G Ninja -DCMAKE_PREFIX_PATH="E:/work/QT/6.8.3/msvc2022_64"
cmake --build build
```

## 二、打包与部署

### 2.1 使用打包脚本

```powershell
cd D:\github\work\PetApp
.\scripts\package.ps1
```

脚本自动执行：
1. 编译 Release 版本
2. 创建 deploy/ 部署目录
3. 复制主程序 PetApp.exe
4. 复制所有技能插件（skill_echo.exe, skill_translate.exe, skill_ocr.exe, skill_chat.exe）
5. 复制 manifest.json 文件
6. 使用 windeployqt 拷贝 Qt 运行时 DLL
7. 复制 VC++ 运行时 DLL
8. 复制配置文件
9. 使用 7-Zip 打包为 PetApp_v1.0.0.zip

### 2.2 手动打包

如果打包脚本执行失败，可手动操作：

```cmd
REM 1. 创建部署目录
mkdir deploy\plugins
mkdir deploy\data\memory
mkdir deploy\config
mkdir deploy\logs\crash

REM 2. 复制主程序
copy PetApp.exe deploy\

REM 3. 复制技能插件
copy plugins\*.exe deploy\plugins\
copy plugins\*.manifest.json deploy\plugins\

REM 4. 使用 windeployqt
cd deploy
"E:\work\QT\6.8.3\msvc2022_64\bin\windeployqt.exe" --release --no-translations PetApp.exe

REM 5. 复制 VC++ 运行时
copy "D:\software\work\VS2022\VC\Redist\MSVC\14.44.35112\x64\Microsoft.VC143.CRT\*.dll" .

REM 6. 复制配置
copy ..\config\default_settings.json config\
```

### 2.3 运行已打包版本

解压 ZIP 包后，**不要直接双击 PetApp.exe**（可能因工作目录问题导致启动失败），请使用以下方式之一运行：

**方式 A：双击 run.bat（推荐）**
1. 解压 ZIP 包后，找到 `run.bat` 文件
2. 双击 `run.bat` 即可启动 PetApp

**方式 B：从命令行运行**
```cmd
cd /d 解压目录
PetApp.exe
```

**方式 C：创建快捷方式**
1. 右键 PetApp.exe → 创建快捷方式
2. 右键快捷方式 → 属性 → 将「起始位置」设为解压目录的完整路径
3. 双击快捷方式运行

> **注意**：打包后的目录包含所有必需的 Qt DLL、VC++ 运行时 DLL 和资源文件，无需安装 Qt 或 Visual Studio。

## 三、运行说明

### 3.1 首次运行

首次运行 PetApp.exe 后，程序会自动：
1. 创建 logs/ 目录（日志和崩溃转储）
2. 创建 data/memory/memory.json（KV 存储）
3. 扫描 plugins/ 目录加载技能
4. 显示主窗口

### 3.2 主窗口操作

| 操作 | 说明 |
|------|------|
| 鼠标拖动 | 按住窗口任意位置拖动 |
| 🔊 回显技能 | 测试技能系统，返回 "Hello: " + 输入 |
| 🎯 晃动 | 桌宠晃动动画 |
| 🏪 技能市场 | 联网浏览和下载技能（需开启网络） |
| ⚙️ 设置 | 打开设置对话框 |

### 3.3 设置对话框

| 设置项 | 说明 |
|--------|------|
| 网络开关 | 启用/禁用网络功能 |
| 性能模式 | 减少动画效果，降低 CPU 占用 |
| 心跳间隔 | 1-30 秒，影响情感衰减速度 |
| 皮肤选择 | 切换桌宠外观（需 config/skins/ 下有图片） |

### 3.4 技能插件

技能插件位于 `plugins/` 目录，每个技能包含：
- `skill_xxx.exe` - 可执行文件
- `skill_xxx.manifest.json` - 元数据文件

**内置技能：**

| 技能 | 文件 | 说明 |
|------|------|------|
| 回显 | skill_echo.exe | 测试用，返回输入文本 |
| 翻译 | skill_translate.exe | 本地词典英汉翻译 |
| OCR | skill_ocr.exe | 图片文字识别（需 tesseract） |
| 对话 | skill_chat.exe | 预定义问答对匹配 |

**热加载：** 运行时向 plugins/ 目录添加或删除技能文件，程序会自动检测并更新技能列表。

## 四、日志与调试

### 4.1 日志文件

所有日志输出到 `logs/crash/app.log`，格式：

```
[2026-05-15 16:00:00.123] [INFO] CrashHandler initialized, crash directory: ...
[2026-05-15 16:00:10.456] [DEBUG] Heartbeat triggered
[2026-05-15 16:00:10.789] [WARN] Skill not found: xxx
```

### 4.2 崩溃转储

程序崩溃时：
1. 生成 `.dmp` 文件到 `logs/crash/` 目录
2. 生成 `crash.log` 记录异常地址和代码
3. 致命错误生成 `fatal_*.log` 报告

### 4.3 调试模式

编译 Debug 版本后，可使用 Visual Studio 附加到进程调试：

1. 打开 Visual Studio
2. 调试 → 附加到进程
3. 选择 PetApp.exe
4. 设置断点进行调试

## 五、常见问题

### Q1: 程序启动后窗口不显示？

检查是否有多个实例运行，关闭所有 PetApp.exe 进程后重试。

### Q2: 技能按钮点击无反应？

1. 检查 plugins/ 目录是否存在
2. 检查技能 exe 和 manifest.json 是否匹配
3. 查看 logs/crash/app.log 获取错误信息

### Q3: 翻译技能不工作？

确认 plugins/skill_translate.exe 和 plugins/skill_translate.manifest.json 存在。

### Q4: OCR 技能报错？

OCR 技能依赖 tesseract.exe，需确保：
1. tesseract.exe 在系统 PATH 中
2. 语言包已安装（如 eng.traineddata）

### Q5: 如何添加自定义皮肤？

1. 在 config/skins/ 目录下创建子目录（如 my_skin/）
2. 放入帧动画图片（frame_0001.png, frame_0002.png, ...）
3. 在设置对话框中选择新皮肤

### Q6: 如何创建新技能？

1. 创建独立控制台 exe 项目
2. 实现 JSON 行协议（stdin 输入，stdout 输出）
3. 编写 manifest.json
4. 编译后放入 plugins/ 目录
5. 程序自动加载
