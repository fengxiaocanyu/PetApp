# PetApp 皮肤数据规格说明

## 概述

PetApp 支持两套皮肤系统：

1. **AppearanceManager（旧版帧动画系统）**：使用图片序列帧，适合简单桌宠
2. **CharacterWidget（新版部件系统）**：使用独立部件贴图，支持交互和动画

当前主窗口使用的是 **CharacterWidget（新版部件系统）**，但 AppearanceManager 仍保留作为备选。

---

## 一、新版部件系统（CharacterWidget）

### 1.1 目录结构

```
config/character/          ← 角色贴图目录
├── body.png               # 身体（必须）
├── head.png               # 头部（必须）
├── arm_left.png           # 左臂（必须）
├── arm_right.png          # 右臂（必须）
├── leg_left.png           # 左腿（必须）
├── leg_right.png          # 右腿（必须）
├── eye_open.png           # 睁眼（必须）
├── eye_closed.png         # 闭眼（可选，用于眨眼动画）
├── mouth_smile.png        # 微笑嘴（必须）
├── mouth_open.png         # 张嘴（可选，用于说话动画）
├── mouth_sad.png          # 难过嘴（可选）
└── mouth_happy.png        # 大笑嘴（可选）
```

### 1.2 部件规格

| 部件 | 文件名 | 推荐尺寸 | 说明 |
|------|--------|---------|------|
| 身体 | `body.png` | 40×50 px | 角色躯干主体 |
| 头部 | `head.png` | 48×48 px | 角色头部，位于身体上方 |
| 左臂 | `arm_left.png` | 14×40 px | 左侧手臂，垂直悬挂 |
| 右臂 | `arm_right.png` | 14×40 px | 右侧手臂，垂直悬挂 |
| 左腿 | `leg_left.png` | 16×30 px | 左侧腿，位于身体下方 |
| 右腿 | `leg_right.png` | 16×30 px | 右侧腿，位于身体下方 |
| 睁眼 | `eye_open.png` | 8×10 px | 正常睁眼状态 |
| 闭眼 | `eye_closed.png` | 8×10 px | 眨眼时使用（可选） |
| 微笑嘴 | `mouth_smile.png` | 16×10 px | 默认微笑表情 |
| 张嘴 | `mouth_open.png` | 16×12 px | 说话时使用（可选） |
| 难过嘴 | `mouth_sad.png` | 16×10 px | 难过表情（可选） |
| 大笑嘴 | `mouth_happy.png` | 16×12 px | 开心表情（可选） |

### 1.3 整体布局

角色在场景中的布局如下（坐标原点为场景左上角）：

```
        ┌──────┐
        │ head │   ← 头部 (centerX-24, centerY-50)
        │ 48x48│
   ┌────┤      ├────┐
   │arm │      │ arm│  ← 左臂 (centerX-28, centerY+5)
   │left│      │right│    右臂 (centerX+14, centerY+5)
   │14x4│      │14x4│
   └────┴──┬───┴────┘
           │ body │      ← 身体 (centerX-20, centerY)
           │ 40x50│
      ┌────┤      ├────┐
      │leg │      │ leg│  ← 左腿 (centerX-14, centerY+50)
      │left│      │right│    右腿 (centerX+4, centerY+50)
      │16x3│      │16x3│
      └────┘      └────┘
```

**参考坐标**：
- 场景中心点：`centerX = 60, centerY = 100`
- 场景大小：`120 × 180 px`
- 窗口大小：`140 × 220 px`

### 1.4 图片要求

| 属性 | 要求 |
|------|------|
| 格式 | PNG（推荐，支持透明背景） |
| 背景 | 透明背景（RGBA） |
| 风格 | 统一画风，所有部件风格一致 |
| 颜色 | 建议使用柔和、明亮的配色 |
| 边缘 | 建议留 1-2px 透明边距，避免贴图紧贴边缘 |

### 1.5 自适应缩放（重要）

**程序会自动缩放图片到合适的显示尺寸，你无需担心图片大小问题！**

- 你可以使用任意尺寸的图片（如 512×512、1024×1024 等）
- 程序会根据每个部件的目标显示尺寸自动缩放，保持宽高比
- 缩放使用 `Qt::SmoothTransformation` 平滑算法，质量高
- 各部件目标显示尺寸如下：

| 部件 | 目标显示尺寸 |
|------|-------------|
| body.png | 40×50 px |
| head.png | 48×48 px |
| arm_left.png / arm_right.png | 14×40 px |
| leg_left.png / leg_right.png | 16×30 px |
| eye_open.png / eye_closed.png | 8×10 px |
| mouth_smile.png / mouth_sad.png | 16×10 px |
| mouth_open.png / mouth_happy.png | 16×12 px |

> **建议**：制作时使用较大的画布（如 256×256 或 512×512），细节更丰富，程序会自动缩放到合适大小。

### 1.6 表情状态映射

程序根据情感向量自动切换表情，各状态对应的贴图需求：

| 情感状态 | 触发条件 | 需要的贴图变化 |
|----------|---------|---------------|
| idle（待机） | 默认状态 | 微笑嘴 + 睁眼，呼吸动画（代码自动） |
| happy（开心） | pleasure > 0.7 | 大笑嘴 + 睁眼 |
| sad（难过） | pleasure < 0.3 | 难过嘴 + 睁眼 |
| tired（疲倦） | tiredness > 0.7 | 微笑嘴 + 半闭眼（代码控制透明度） |
| curious（好奇） | curiosity > 0.7 | 微笑嘴 + 睁眼 |
| talking（说话） | 技能执行时 | 张嘴/闭嘴交替（代码控制） |

### 1.7 动作动画

程序内置的动作动画（无需额外贴图）：

| 动作 | 效果 | 实现方式 |
|------|------|---------|
| 呼吸 | 身体±2px 上下起伏 | 代码控制位置偏移 |
| 眨眼 | 随机 2-5 秒眨眼一次 | 代码控制透明度 |
| 挥手 | 右臂左右摆动 | 代码控制旋转角度 |
| 跳跃 | 身体上下弹跳 | 代码控制位置偏移 |
| 脸红 | 身体透明度变化 | 代码控制透明度 |

## 二、旧版帧动画系统（AppearanceManager）

### 2.1 目录结构

```
config/skins/
├── default/               # 默认皮肤（必须）
│   ├── frame_0001.png     # 第1帧
│   ├── frame_0002.png     # 第2帧
│   ├── frame_0003.png     # 第3帧
│   ├── frame_0004.png     # 第4帧
│   └── frame_0005.png     # 第5帧
├── happy/                 # 开心表情（可选）
│   ├── frame_0001.png
│   └── frame_0002.png
├── sad/                   # 难过表情（可选）
│   ├── frame_0001.png
│   └── frame_0002.png
├── tired/                 # 疲倦表情（可选）
│   ├── frame_0001.png
│   └── frame_0002.png
└── curious/               # 好奇表情（可选）
    ├── frame_0001.png
    └── frame_0002.png
```

### 2.2 帧动画规格

| 属性 | 要求 |
|------|------|
| 格式 | PNG（推荐，支持透明背景） |
| 尺寸 | 128×128 像素（推荐） |
| 背景 | 透明背景（RGBA） |
| 命名规则 | `frame_0001.png`（4 位数字序号，从 0001 开始） |
| 帧数 | 每个动画至少 1 帧，推荐 4-10 帧 |
| 帧率 | 程序默认 200ms/帧（5 FPS） |

### 2.3 表情映射

| 情感状态 | 对应目录 | 触发条件 |
|----------|---------|----------|
| idle（待机） | `default/` | 默认 |
| happy（开心） | `happy/` | pleasure > 0.7 |
| sad（难过） | `sad/` | pleasure < 0.3 |
| tired（疲倦） | `tired/` | tiredness > 0.7 |
| curious（好奇） | `curious/` | curiosity > 0.7 |

## 三、给 AI 制作皮肤的建议

### 3.1 推荐方案：优先制作新版部件系统贴图

新版部件系统支持交互（点击不同部位有不同反应），体验更好。建议制作以下文件：

**必须制作（9 个文件）：**
```
config/character/
├── body.png           # 身体 - 40×50
├── head.png           # 头部 - 48×48
├── arm_left.png       # 左臂 - 14×40
├── arm_right.png      # 右臂 - 14×40
├── leg_left.png       # 左腿 - 16×30
├── leg_right.png      # 右腿 - 16×30
├── eye_open.png       # 睁眼 - 8×10
├── mouth_smile.png    # 微笑嘴 - 16×10
```

**推荐额外制作（5 个文件，增强体验）：**
```
├── eye_closed.png     # 闭眼 - 8×10（眨眼动画）
├── mouth_open.png     # 张嘴 - 16×12（说话动画）
├── mouth_sad.png      # 难过嘴 - 16×10（难过表情）
├── mouth_happy.png    # 大笑嘴 - 16×12（开心表情）
```

### 3.2 设计风格建议

- **Q 版风格**：大头小身的比例最适合桌宠
- **颜色搭配**：建议使用 3-5 种主色调，保持统一
- **线条风格**：圆润、柔和的线条更适合桌宠
- **表情变化**：嘴型和眼睛的变化是表情的核心

### 3.3 参考尺寸比例

```
头部: 48×48 px  (大头 Q 版)
身体: 40×50 px  (比头略小)
手臂: 14×40 px  (细长)
腿部: 16×30 px  (短小)
眼睛: 8×10 px   (大眼 Q 版)
嘴巴: 16×10 px  (小巧)
```

### 3.4 制作流程建议

1. **先设计角色概念图**：确定整体风格和配色
2. **拆分部件**：按上述规格拆分各部件
3. **导出 PNG**：透明背景，按文件名规范导出
4. **测试**：放入 `config/character/` 目录，运行 PetApp 查看效果
5. **调整**：根据实际显示效果微调尺寸和位置

### 3.5 可选：同时制作帧动画皮肤

如果想让 AppearanceManager 也能使用，可以额外制作帧动画皮肤：
- 将角色整体渲染为 128×128 的帧序列
- 放入 `config/skins/default/` 目录
- 不同表情放入对应子目录

## 四、快速开始

### 4.1 最小可行皮肤

只需 9 个 PNG 文件即可让桌宠显示：

```
config/character/
├── body.png
├── head.png
├── arm_left.png
├── arm_right.png
├── leg_left.png
├── leg_right.png
├── eye_open.png
├── mouth_smile.png
```

### 4.2 测试方法

将制作好的贴图放入 `config/character/` 目录后，运行 PetApp：
- 桌宠应显示各部件组合的完整形象
- 点击不同部位会有不同反应
- 呼吸动画自动生效
- 眨眼动画自动生效

### 4.3 常见问题

**Q: 贴图不显示？**
A: 检查文件名是否完全匹配（区分大小写），检查 PNG 是否为透明背景。

**Q: 部件位置不对？**
A: 部件的显示位置由代码中的偏移量控制。如果贴图尺寸与推荐尺寸差异较大，可能需要调整代码中的坐标。

**Q: 如何制作多套皮肤？**
A: 目前新版部件系统只支持一套贴图。如需多套皮肤，建议使用 AppearanceManager 的帧动画系统，将不同皮肤放在 `config/skins/` 下的不同子目录中。
