# PetApp 桌宠系统 - 功能手册

## 一、系统架构

### 1.1 整体架构

```
┌─────────────────────────────────────────────────┐
│              表现层（Appearance & Output）       │
│  ┌──────────────┬──────────────┬─────────────┐ │
│  │AppearanceMgr │ VoiceMgr     │ ActionMgr   │ │
│  └──────────────┴──────────────┴─────────────┘ │
└─────────────────────────────────────────────────┘
                        ▲ 事件总线
┌─────────────────────────────────────────────────┐
│              决策与核心逻辑（Core）              │
│  ┌──────────┬──────────┬──────────┬──────────┐ │
│  │MemoryMod │Heartbeat │EmotionMod│Capability│ │
│  └──────────┴──────────┴──────────┴──────────┘ │
└─────────────────────────────────────────────────┘
                        ▲ 事件总线
┌─────────────────────────────────────────────────┐
│              技能插件层（Skills）                │
│  ┌──────────────────────────────────────────┐   │
│  │ SkillManager → 启动子进程 → skill_*.exe   │   │
│  └──────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

### 1.2 三层架构

| 层级 | 模块 | 职责 |
|------|------|------|
| **核心层** | EventBus, MemoryModule, HeartbeatModule, EmotionModule, CapabilityManager, SkillManager | 数据存储、心跳驱动、情感计算、能力管理、技能调度 |
| **表现层** | AppearanceManager, VoiceManager, ActionManager | 形象渲染、语音输出、动作执行 |
| **技能层** | skill_echo, skill_translate, skill_ocr, skill_chat | 独立子进程，通过 JSON 协议通信 |

### 1.3 通信机制

所有模块间通信通过 **EventBus（事件总线）** 进行：

- 发布者：`EventBus::instance().emitEvent("event_name", data)`
- 订阅者：`EventBus::instance().on("event_name", callback)`
- 取消订阅：`EventBus::instance().off("event_name", callback)`

**预定义事件：**

| 事件名 | 触发者 | 数据 | 说明 |
|--------|--------|------|------|
| heartbeat | HeartbeatModule | 无 | 定时心跳（默认 10 秒） |
| emotion_changed | EmotionModule | EmotionState | 情感向量变化 |
| online_status_changed | CapabilityManager | bool | 网络状态变化 |
| show_bubble | ActionManager | QJsonObject | 显示气泡消息 |
| settings_changed | SettingsDialog | QJsonObject | 设置变更 |

## 二、核心模块功能

### 2.1 EventBus（事件总线）

**类**: `petapp::core::EventBus`

**功能**:
- 全局单例模式
- 基于 QObject 信号槽 + 回调函数列表
- 支持任意 QVariant 类型的事件数据
- 线程安全的事件发布

**接口**:
```cpp
// 获取单例
static EventBus& instance();

// 发布事件
void emitEvent(const QString& eventName, const QVariant& data = QVariant());

// 订阅事件
void on(const QString& eventName, std::function<void(const QVariant&)> callback);

// 取消订阅
void off(const QString& eventName, std::function<void(const QVariant&)> callback);
```

### 2.2 MemoryModule（存储模块）

**类**: `petapp::core::MemoryModule`

**功能**:
- 基于 QJsonDocument 的键值存储
- 持久化到 `data/memory/memory.json`
- 支持字符串、数字、布尔、数组、对象等类型

**接口**:
```cpp
void load();   // 从文件加载
void save();   // 保存到文件

void setValue(const QString& key, const QVariant& value);
QVariant getValue(const QString& key, const QVariant& defaultValue = QVariant()) const;
```

### 2.3 HeartbeatModule（心跳模块）

**类**: `petapp::core::HeartbeatModule`

**功能**:
- 基于 QTimer 的定时心跳
- 默认间隔 10 秒
- 通过 EventBus 发布 heartbeat 事件
- 可动态调整间隔

**接口**:
```cpp
void start();   // 启动心跳
void stop();    // 停止心跳
void setInterval(int ms);  // 设置间隔（毫秒）
int interval() const;
```

### 2.4 EmotionModule（情感模块）

**类**: `petapp::core::EmotionModule`

**功能**:
- 三维情感向量：愉悦（pleasure）、好奇（curiosity）、疲倦（tiredness）
- 每个维度范围 0.0 - 1.0，初始值 0.5
- 每心跳自然衰减 0.02
- 外部事件可增减情感值
- 通过 EventBus 发布 emotion_changed 事件

**数据结构**:
```cpp
struct EmotionState {
    double pleasure = 0.5;   // 愉悦
    double curiosity = 0.5;  // 好奇
    double tiredness = 0.5;  // 疲倦
};
```

**接口**:
```cpp
void modify(const QString& dimension, double delta);  // 修改情感值
void setEmotion(const EmotionState& state);           // 设置情感状态
void decay(double amount);                            // 情感衰减
EmotionState currentEmotion() const;                  // 获取当前情感
```

### 2.5 CapabilityManager（能力管理器）

**类**: `petapp::core::CapabilityManager`

**功能**:
- 监听网络状态（QNetworkInformation）
- 手动离线模式开关
- 通过 EventBus 发布 online_status_changed 事件
- 默认离线模式

**接口**:
```cpp
void initialize();                    // 初始化
bool isNetworkAvailable() const;      // 网络是否可用
void setManualOffline(bool offline);  // 设置手动离线
bool isManualOffline() const;         // 是否手动离线
bool isOnline() const;                // 是否在线
void setOnline();                     // 设为在线
void setOffline();                    // 设为离线
```

### 2.6 SkillManager（技能管理器）

**类**: `petapp::core::SkillManager`

**功能**:
- 扫描 plugins/ 目录下的 *.exe
- 读取同名的 manifest.json 注册技能
- QProcess 启动子进程，stdin/stdout JSON 通信
- 5 秒超时保护
- QFileSystemWatcher 热加载
- 技能可用性检查（网络/资源）

**技能信息结构**:
```cpp
struct SkillInfo {
    QString id;                // 技能唯一标识
    QString name;              // 技能显示名称
    QString version;           // 版本号
    bool requiresNetwork;      // 是否需要网络
    int resourceWeight;        // 资源消耗权重 (0-10)
    QString executable;        // 可执行文件名
    QString description;       // 描述
    QString manifestPath;      // manifest.json 路径
    QString exePath;           // exe 完整路径
};
```

**接口**:
```cpp
void initialize();                                              // 初始化
void scanSkills();                                              // 扫描技能
bool runSkill(const QString& skillId, const QJsonObject& params,
              std::function<void(const QJsonObject&)> callback); // 运行技能
bool canRunSkill(const QString& skillId, bool isNetworkAvailable) const; // 检查可用性
QStringList skillsRequiringNetwork() const;                     // 需要网络的技能
QMap<QString, SkillInfo> availableSkills() const;               // 所有技能
```

## 三、表现层模块功能

### 3.1 AppearanceManager（外观管理器）

**类**: `petapp::appearance::AppearanceManager`

**功能**:
- 加载 config/skins/ 下的图片序列
- QTimer 控制帧动画
- 表情变化（通过 emotion_changed 事件）
- 皮肤切换
- 提供 QLabel 用于显示

**皮肤图片规格**:
- 推荐尺寸：128×128 像素
- 格式：PNG（支持透明背景 RGBA）
- 命名规则：`frame_0001.png`（4 位数字序号，从 0001 开始）
- 每个皮肤至少 1 帧，推荐 4-10 帧
- 无皮肤文件时显示占位文本 "(Pet)"

**接口**:
```cpp
void initialize();                                    // 初始化
QLabel* displayLabel();                               // 获取显示标签
void setEmotion(const QString& emotion);              // 设置表情
void playAnimation(const QString& animationName);     // 播放动画
void setSkin(const QString& skinName);                // 切换皮肤
QStringList availableSkins() const;                   // 可用皮肤列表
```

### 3.2 ActionManager（动作管理器）

**类**: `petapp::action::ActionManager`

**功能**:
- 显示气泡对话
- 桌宠移动
- 晃动动画
- 通过 EventBus 接收动作指令

**接口**:
```cpp
void initialize(QWidget* parent);                     // 初始化
void showBubble(const QString& text, int durationMs); // 显示气泡
void moveTo(int x, int y);                            // 移动到指定位置
void shake();                                         // 晃动动画
```

### 3.3 VoiceManager（语音管理器）

**类**: `petapp::voice::VoiceManager`

**功能**:
- 使用 QTextToSpeech（Windows SAPI）实现 TTS
- 语速、音量调节
- 优雅降级（QTextToSpeech 不可用时不崩溃）

**接口**:
```cpp
void initialize();                                    // 初始化
void speak(const QString& text);                      // 朗读文本
void setRate(double rate);                            // 设置语速 (-1.0 ~ 1.0)
void setVolume(double volume);                        // 设置音量 (0.0 ~ 1.0)
bool isAvailable() const;                             // 是否可用
```

## 四、技能插件系统

### 4.1 技能协议

技能插件为独立控制台 exe，通过 stdin/stdout 使用 JSON 行协议通信。

**请求格式**（宿主 → 技能）：
```json
{"method":"execute","id":1,"params":{"input":"...","config":{...}}}
```

**响应格式**（技能 → 宿主，成功）：
```json
{"id":1,"result":"处理结果","error":null}
```

**响应格式**（技能 → 宿主，失败）：
```json
{"id":1,"result":null,"error":{"code":-1,"message":"错误信息"}}
```

### 4.2 manifest.json 规范

```json
{
  "id": "com.example.translate",
  "name": "离线翻译",
  "version": "1.0.0",
  "requires_network": false,
  "resource_weight": 2,
  "executable": "skill_translate.exe",
  "description": "基于本地词典的英汉翻译"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 技能唯一标识符 |
| name | string | 是 | 技能显示名称 |
| version | string | 否 | 版本号，默认 "1.0.0" |
| requires_network | bool | 否 | 是否需要网络，默认 false |
| resource_weight | int | 否 | 资源消耗权重 0-10，默认 1 |
| executable | string | 是 | 可执行文件名 |
| description | string | 否 | 技能描述 |

### 4.3 内置技能

#### skill_echo（回显技能）
- **ID**: `com.petapp.echo`
- **功能**: 将输入文本加上 "Hello: " 前缀返回
- **网络需求**: 否
- **用途**: 测试技能系统

#### skill_translate（翻译技能）
- **ID**: `com.petapp.translate`
- **功能**: 基于本地词典的英汉翻译
- **网络需求**: 否
- **参数**: `input`（待翻译文本），`config.src_lang`（源语言），`config.tgt_lang`（目标语言）

#### skill_ocr（OCR 技能）
- **ID**: `com.petapp.ocr`
- **功能**: 图片文字识别
- **网络需求**: 否
- **依赖**: tesseract.exe
- **参数**: `input`（图片路径）

#### skill_chat（对话技能）
- **ID**: `com.petapp.chat`
- **功能**: 预定义问答对匹配
- **网络需求**: 否
- **参数**: `input`（用户输入文本）

## 五、离线自适应功能

### 5.1 离线模式

- 系统默认关闭网络功能
- 所有内置技能有本地实现
- 设置对话框中提供明确的网络开关

### 5.2 自适应降级

- 技能调用前检查 manifest 中的 `requires_network` 字段
- 网络不可用时，依赖网络的技能自动禁用
- 用户点击禁用技能时弹出提示气泡

### 5.3 降级流程

```
用户点击技能按钮
    ↓
CapabilityManager.isNetworkAvailable()
    ↓
SkillManager.canRunSkill(skillId, isNetworkAvailable)
    ├─ 技能存在 && (!requires_network || networkAvailable) → 执行技能
    └─ 否则 → 显示提示气泡 "⚠️ 该技能需要网络连接，当前处于离线模式"
```

## 六、崩溃报告功能

### 6.1 消息捕获

使用 `qInstallMessageHandler` 捕获所有 Qt 消息：
- DEBUG / INFO / WARN / CRITICAL / FATAL
- 写入 `logs/crash/app.log`
- 同时输出到 stderr

### 6.2 异常捕获

使用 `SetUnhandledExceptionFilter` 捕获原生异常：
- 生成 `.dmp` minidump 到 `logs/crash/`
- 记录异常地址和代码到 `crash.log`

### 6.3 日志格式

```
[2026-05-15 16:00:00.123] [INFO] CrashHandler initialized, crash directory: ...
[2026-05-15 16:00:10.456] [DEBUG] Heartbeat triggered
[2026-05-15 16:00:10.789] [WARN] Skill not found: xxx
```

## 七、技能市场功能

### 7.1 功能概述

- 联网浏览可用技能列表
- 显示技能名称、版本、描述、网络需求
- 已安装技能标记为绿色"已安装"
- 下载技能包到 plugins/ 目录
- 下载后自动触发技能管理器重新扫描

### 7.2 使用条件

- 需要开启网络（设置中启用）
- 需要技能市场 API 服务端（示例 URL: https://api.petapp.dev/skills/list）

### 7.3 API 接口

> **注意**：以下 API URL 为示例地址，`api.petapp.dev` 并非真实服务端。用户需自行部署技能市场 REST API 服务端（可使用 Node.js、Python 等实现），或修改 `src/ui/SkillMarketDialog.cpp` 中的 URL 指向自定义服务端。

**获取技能列表**:
```
GET https://api.petapp.dev/skills/list
Response: [{"id":"...","name":"...","version":"...","description":"...","requires_network":false,"download_url":"..."}]
```

**下载技能包**:
```
GET {download_url}
Response: binary (ZIP 包)
