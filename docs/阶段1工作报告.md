## 二、编译问题及解决方案

### 问题 1：skill_echo 文件编码导致编译失败

**现象**：C4819 警告 + `input` 变量未定义
**原因**：文件包含中文注释，MSVC 在 GBK 代码页下无法正确解析
**解决**：将 skill_echo/main.cpp 改为纯英文注释

### 问题 2：SkillManager.h 前置声明命名空间冲突

**现象**：`class QFileSystemWatcher*` 被解析为 `petapp::core::QFileSystemWatcher`
**原因**：在 `namespace petapp { namespace core { ... }}` 内部使用 `class Xxx*` 前置声明时，编译器将其解析为当前命名空间下的类型
**解决**：改为直接 `#include <QFileSystemWatcher>` 和 `#include <QProcess>`

### 问题 3：MainWindow.cpp 参数名冲突

**现象**：C4458 警告 - `data` 参数隐藏了 `QWidget::data` 成员
**原因**：`QWidget` 基类有 `data` 属性
**解决**：将 lambda 和函数参数名从 `data` 改为 `variant`

### 问题 4：skill_echo 自动启用 AUTOMOC

**现象**：skill_echo 目标生成了无用的 moc 文件
**原因**：全局 `CMAKE_AUTOMOC ON` 影响了所有目标
**解决**：在 skill_echo 目标上显式设置 `AUTOMOC OFF`
