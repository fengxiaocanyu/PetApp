## 一、已完成模块清单

### 1. 外观模块（Appearance）

| 模块 | 文件 | 功能 |
|------|------|------|
| AppearanceManager | `src/appearance/AppearanceManager.h/.cpp` | 帧动画渲染，加载 config/skins/ 图片序列，情感→表情自动映射 |

**关键实现细节：**
- 支持从 `config/skins/<skinName>/` 目录加载图片序列
- 子目录名作为动画名称（idle、happy、sad、tired、curious）
- 无子目录时直接加载目录下图片作为 idle 动画
- 无皮肤文件时显示占位文本 "(Pet)"
- 通过 EventBus 订阅 `emotion_changed` 事件自动切换表情
- 情感向量阈值映射：tiredness>0.7→tired, pleasure>0.7→happy, curiosity>0.7→curious, pleasure<0.3→sad, 其他→idle

### 2. 动作模块（Action）

| 模块 | 文件 | 功能 |
|------|------|------|
| ActionManager | `src/action/ActionManager.h/.cpp` | showBubble、moveTo、shake 动作，通过 EventBus 接收指令 |

**关键实现细节：**
- `showBubble()` 通过 EventBus 发布 `show_bubble` 事件，由 MainWindow 中的 BubbleWidget 显示
- `moveTo(x, y)` 直接移动目标窗口
- `shake()` 使用 QTimer 驱动 10 帧晃动动画（±5px 偏移），完成后恢复原位
- 通过 EventBus 订阅 `action_command` 事件接收外部指令

### 3. 语音模块（Voice）

| 模块 | 文件 | 功能 |
|------|------|------|
| VoiceManager | `src/voice/VoiceManager.h/.cpp` | QTextToSpeech TTS，支持语速/音量调节 |

**关键实现细节：**
- 使用条件编译 `#ifdef HAS_TEXT_TO_SPEECH` 处理 Qt 未安装 TextToSpeech 组件的情况
- CMakeLists.txt 中 `find_package(Qt6 QUIET COMPONENTS TextToSpeech)` 可选查找
- 无 TTS 时优雅降级：`isAvailable()` 返回 false，所有 speak/stop 调用无操作
- 通过 EventBus 订阅 `voice_command` 事件接收外部指令

### 4. 集成交互逻辑（MainWindow 更新）

**集成内容：**
- 使用 `AppearanceManager::displayLabel()` 替换原来的宠物 QLabel
- 初始化所有表现层模块（AppearanceManager、ActionManager、VoiceManager）
- 心跳事件 → 调用 `EmotionModule::decay(0.02)` 触发情感衰减
- 情感变化 → 更新状态标签显示愉悦/好奇/疲倦数值
- 在线状态变化 → 显示气泡提示
- 晃动按钮 → 调用 `ActionManager::shake()`
- 回显技能按钮 → 调用 `SkillManager::runSkill()`

## 二、编译问题及解决方案

### 问题 1：Qt6TextToSpeech 组件未安装

**现象**：CMake 错误 - `Failed to find required Qt component "TextToSpeech"`
**原因**：当前 Qt 6.8.3 安装未包含 TextToSpeech 模块
**解决**：
1. 将 TextToSpeech 从 `REQUIRED` 改为 `QUIET` 可选查找
2. 使用 `if(Qt6TextToSpeech_FOUND)` 条件链接
3. 定义 `HAS_TEXT_TO_SPEECH` 宏供代码使用
4. VoiceManager 中使用 `#ifdef HAS_TEXT_TO_SPEECH` 条件编译

### 问题 2：VoiceManager 未使用参数警告

**现象**：C4100 警告 - `text`、`rate`、`volume` 参数未使用
**原因**：无 TTS 时，speak/setRate/setVolume 函数体为空
**解决**：在 `#else` 分支中添加 `Q_UNUSED()` 宏
