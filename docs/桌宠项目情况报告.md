# PetApp 桌宠项目情况报告

## 一、项目要求（上部分）

### 1.1 项目概述

开发一个 Windows 原生桌面桌宠应用程序（PetApp），使用 C++17 / Qt 6.8.3 开发，具备以下核心特性：

- **可自定义形象**：支持皮肤切换和帧动画
- **模块化架构**：核心层、表现层、技能层三层分离
- **离线优先**：默认离线模式，所有技能有本地实现
- **可移植**：拷贝即用，无需安装 Qt 或 Visual Studio
- **技能插件系统**：独立子进程（exe）通过 JSON over stdin/stdout 通信
- **情感系统**：三维情感向量（愉悦/好奇/疲倦）
- **语音输出**：TTS 支持（QTextToSpeech）
- **崩溃报告**：minidump 生成和日志记录
- **技能市场**：联网浏览和下载技能插件

### 1.2 技术栈要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 11 (x86_64) |
| 编译器 | Visual Studio 2022 (MSVC v143) |
| 构建系统 | CMake 3.22+ / Ninja |
| Qt 版本 | 6.8.3 (msvc2022_64) |
| C++ 标准 | C++17 |
| Windows SDK | 10.0.26100.0 |

## 二、项目达成情况（下部分）

### 2.1 开发阶段完成情况

#### 阶段 0：项目基础与工具链配置 ✅
- CMake 工程骨架
- PlatformDefines.h（Windows 宏保护）
- main.cpp（QApplication 初始化）
- config/default_settings.json
- **EventBus 模块**：单例模式，emitEvent()/on()/off()
- **MemoryModule 模块**：基于 QJsonDocument 的 KV 存储

#### 阶段 1：主框架与插件管理（MVP） ✅
- **HeartbeatModule**：QTimer 驱动，默认 10 秒心跳
- **EmotionModule**：三维情感向量（愉悦/好奇/疲倦 0-1）
- **CapabilityManager**：网络状态监听 + 手动离线模式
- **SkillManager**：扫描 plugins/，QProcess 子进程管理，JSON 协议，5 秒超时，热加载
- **skill_echo**：回显技能插件
- **MainWindow**：透明无边框窗口
- **BubbleWidget**：半透明圆角气泡

#### 阶段 2：桌宠外观与基本交互 ✅
- **AppearanceManager**：图片序列帧动画，表情变化，皮肤切换
- **ActionManager**：showBubble()/moveTo()/shake()
- **VoiceManager**：QTextToSpeech TTS，语速/音量调节，优雅降级
- 心跳 → 表情随机微动，鼠标拖动窗口

#### 阶段 3：三个核心技能 ✅
- **skill_translate**：本地词典英汉翻译（内置 80+ 词条）
- **skill_ocr**：通过子进程调用 tesseract.exe
- **skill_chat**：预定义问答对匹配

#### 阶段 4：离线自适应与设置界面 ✅
- **SettingsDialog**：网络开关、性能模式、心跳间隔、皮肤选择
- 自适应降级：技能调用前检查 manifest 中的 requires_network

#### 阶段 5：打包与发布 ✅
- **package.ps1**：编译 Release → windeployqt → VC++ 运行时 → ZIP 打包
- README.md 更新

#### 阶段 6：可选增强 ✅
- **CrashHandler**：qInstallMessageHandler + SetUnhandledExceptionFilter，minidump
- 技能协议支持任何语言编写的 exe
- **SkillMarketDialog**：联网浏览/下载技能插件

### 2.2 项目架构方案

#### 三层架构

```
┌─────────────────────────────────────────────────┐
│              表现层（Appearance & Output）       │
│  ┌──────────────┬──────────────┬─────────────┐ │
│  │AppearanceMgr │ VoiceMgr     │ ActionMgr   │ │
│  └──────────────┴──────────────┴─────────────┘ │
└─────────────────────────────────────────────────┘
                        ▲ 事件总线
┌─────────────────────────────────────────────────┐
│              决策与核心逻辑（Core）              │
│  ┌──────────┬──────────┬──────────┬──────────┐ │
│  │MemoryMod │Heartbeat │EmotionMod│Capability│ │
│  └──────────┴──────────┴──────────┴──────────┘ │
└─────────────────────────────────────────────────┘
                        ▲ 事件总线
┌─────────────────────────────────────────────────┐
│              技能插件层（Skills）                │
│  ┌──────────────────────────────────────────┐   │
│  │ SkillManager → 启动子进程 → skill_*.exe   │   │
│  └──────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

#### 模块解耦方案
- 严格分层：Core → UI/Appearance/Voice/Action → Skills
- 层间通过 EventBus 事件通信
- 禁止跨模块直接函数调用

#### 技能插件协议
- JSON 行协议：stdin 输入请求，stdout 输出响应
- 单次任务后退出，禁止长连接
- 5 秒超时保护

### 2.5 遗留问题

1. **干净 Windows 虚拟机测试未执行**：需手动验证打包后的 ZIP 在无 Qt/VC++ 环境下的运行
2. **skill_ocr 依赖 tesseract.exe**：需预置语言包到 `data/models/tessdata/`
3. **技能市场 API 为示例 URL**：需部署实际服务端
4. **皮肤资源需用户自行准备**：`config/skins/` 下需要 PNG 图片
5. **翻译词典可选**：不提供 `dictionary.json` 则使用内置小词典
