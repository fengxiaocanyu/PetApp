# PetApp 编译环境指南

## 一、环境要求

| 软件 | 版本要求 | 说明 |
|------|---------|------|
| Visual Studio 2022 | 17.x+ (MSVC v143) | 必须安装"使用 C++ 的桌面开发"工作负载 |
| Windows SDK | 10.0.26100.0+ | VS2022 安装时可选，用于 dbghelp.lib 等 |

## 二、环境变量问题（常见编译失败原因）

### 2.1 问题现象

执行 `VsDevCmd.bat` 后，编译时出现：
```
fatal error C1083: 无法打开包括文件: "type_traits": No such file or directory
```
或链接时出现：
```
LINK : fatal error LNK1104: 无法打开文件 "dbghelp.lib"
```

### 2.2 原因

`VsDevCmd.bat` 在嵌套调用（如通过 `call` 命令在另一个批处理中调用）时，可能无法正确设置 `INCLUDE` 和 `LIB` 环境变量。这是因为 `VsDevCmd.bat` 依赖于当前工作目录为 VS2022 安装目录来查找 `vsdevcmd/ext/` 目录。

### 2.3 解决方案

**方案 A（推荐）：手动设置环境变量**

每次编译前，执行以下完整命令：

```cmd
call "D:\software\work\VS2022\Common7\Tools\VsDevCmd.bat" -arch=x64 -host_arch=x64
set "INCLUDE=D:\software\work\VS2022\VC\Tools\MSVC\14.44.35207\include;D:\software\work\VS2022\VC\Tools\MSVC\14.44.35207\atlmfc\include;C:\Program Files (x86)\Windows Kits\10\Include\10.0.26100.0\ucrt;C:\Program Files (x86)\Windows Kits\10\Include\10.0.26100.0\um;C:\Program Files (x86)\Windows Kits\10\Include\10.0.26100.0\shared"
set "LIB=D:\software\work\VS2022\VC\Tools\MSVC\14.44.35207\lib\x64;D:\software\work\VS2022\VC\Tools\MSVC\14.44.35207\atlmfc\lib\x64;C:\Program Files (x86)\Windows Kits\10\Lib\10.0.26100.0\ucrt\x64;C:\Program Files (x86)\Windows Kits\10\Lib\10.0.26100.0\um\x64"
```

> **注意**：上述路径中的版本号（14.44.35207、10.0.26100.0）需根据你实际安装的 VS2022 和 Windows SDK 版本调整。

**方案 B：使用完整的 CMake 路径**

VsDevCmd 会重置 PATH，导致 `cmake` 命令找不到。需要使用完整路径：

```cmd
"D:\software\work\VS2022\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe" --build D:\github\work\PetApp\build
```

**方案 C：创建编译脚本**

创建 `scripts/build.bat` 文件，内容如下：

```batch
@echo off
call "D:\software\work\VS2022\Common7\Tools\VsDevCmd.bat" -arch=x64 -host_arch=x64
set "INCLUDE=D:\software\work\VS2022\VC\Tools\MSVC\14.44.35207\include;D:\software\work\VS2022\VC\Tools\MSVC\14.44.35207\atlmfc\include;C:\Program Files (x86)\Windows Kits\10\Include\10.0.26100.0\ucrt;C:\Program Files (x86)\Windows Kits\10\Include\10.0.26100.0\um;C:\Program Files (x86)\Windows Kits\10\Include\10.0.26100.0\shared"
set "LIB=D:\software\work\VS2022\VC\Tools\MSVC\14.44.35207\lib\x64;D:\software\work\VS2022\VC\Tools\MSVC\14.44.35207\atlmfc\lib\x64;C:\Program Files (x86)\Windows Kits\10\Lib\10.0.26100.0\ucrt\x64;C:\Program Files (x86)\Windows Kits\10\Lib\10.0.26100.0\um\x64"
"D:\software\work\VS2022\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe" -S D:\github\work\PetApp -B D:\github\work\PetApp\build -G Ninja -DCMAKE_PREFIX_PATH="E:/work/QT/6.8.3/msvc2022_64"
"D:\software\work\VS2022\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe" --build D:\github\work\PetApp\build
echo Build complete.

```


## 五、常见编译错误及解决方法

### 5.1 type_traits 找不到

**错误信息**：
```
fatal error C1083: 无法打开包括文件: "type_traits": No such file or directory
```

**原因**：`INCLUDE` 环境变量未设置或设置不正确，编译器找不到 C++ 标准库头文件。

**解决**：手动设置 `INCLUDE` 环境变量（见 2.3 节方案 A）。

### 5.2 dbghelp.lib 找不到

**错误信息**：
```
LINK : fatal error LNK1104: 无法打开文件 "dbghelp.lib"
```

**原因**：`LIB` 环境变量未设置或设置不正确，链接器找不到 Windows SDK 的库文件。

**解决**：手动设置 `LIB` 环境变量（见 2.3 节方案 A）。

### 5.3 cmake 命令找不到

**错误信息**：
```
'cmake' 不是内部或外部命令，也不是可运行的程序
```

**原因**：VsDevCmd.bat 重置了 PATH 环境变量，而 CMake 路径不在新的 PATH 中。

**解决**：使用 CMake 的完整路径：
```
"D:\software\work\VS2022\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe"
```

### 5.4 Qt 相关错误

**错误信息**：
```
CMake Error at ...: Failed to find required Qt component "Widgets"
```

**原因**：`CMAKE_PREFIX_PATH` 未指向正确的 Qt 安装路径。

**解决**：配置时指定正确的 Qt 路径：
```
-DCMAKE_PREFIX_PATH="E:/work/QT/6.8.3/msvc2022_64"
```

### 5.5 程序启动后立即退出

**错误信息**：
```
QCoreApplication::applicationDirPath: Please instantiate the QApplication object first
```

**原因**：`CrashHandler::initialize()` 在 `QApplication` 对象创建之前被调用。

**解决**：确保 `main.cpp` 中先创建 `QApplication`，再调用 `CrashHandler::initialize()`。

### 5.6 程序启动后窗口不显示

**可能原因**：
1. 缺少 Qt 平台插件（`qwindows.dll` 或 `qwindowsd.dll`）
2. 多个实例运行冲突

**解决**：
1. 运行 `windeployqt` 部署 Qt DLL
2. 关闭所有 PetApp.exe 进程后重试
