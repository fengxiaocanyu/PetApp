# PetApp 桌宠系统 - 开发工作报告

## 一、项目概述

PetApp 是一个 Windows 原生桌面桌宠应用程序，使用 C++17 / Qt 6.8.3 开发，具备可自定义形象、模块化架构、离线优先、可移植（拷贝即用）等特性。技能插件以独立子进程（exe）形式存在，通过 JSON over stdin/stdout 通信。

## 二、开发环境

| 项目 | 版本 |
|------|------|
| 操作系统 | Windows 11 (x86_64) |

| 构建系统 | Ninja |

| Windows SDK | 10.0.26100.0 |

## 三、完成情况

### 阶段 0：项目基础与工具链配置 ✅
- CMake 工程骨架（PetApp/ 目录结构）
- PlatformDefines.h（Windows 宏保护）
- main.cpp（QApplication 初始化）
- config/default_settings.json
- **EventBus 模块**：单例模式，emitEvent()/on()/off()，基于 QObject 信号槽
- **MemoryModule 模块**：基于 QJsonDocument 的 KV 存储，读写 data/memory/memory.json

### 阶段 1：主框架与插件管理（MVP） ✅
- **HeartbeatModule**：QTimer 驱动，默认 10 秒心跳事件
- **EmotionModule**：三维情感向量（愉悦/好奇/疲倦 0-1），心跳衰减 0.02
- **CapabilityManager**：网络状态监听 + 手动离线模式开关
- **SkillManager**：扫描 plugins/ 目录，QProcess 子进程管理，JSON 协议通信，5 秒超时，QFileSystemWatcher 热加载
- **skill_echo**：回显技能插件
- **MainWindow**：透明无边框窗口，集成所有模块
- **BubbleWidget**：半透明圆角气泡，自动消失

### 阶段 2：桌宠外观与基本交互 ✅
- **AppearanceManager**：图片序列帧动画，表情变化，皮肤切换
- **ActionManager**：showBubble()/moveTo()/shake() 动作接口
- **VoiceManager**：QTextToSpeech TTS，语速/音量调节，优雅降级
- 心跳 → 表情随机微动，鼠标拖动窗口

### 阶段 3：三个核心技能 ✅
- **skill_translate**：本地词典英汉翻译
- **skill_ocr**：通过子进程调用 tesseract.exe
- **skill_chat**：预定义问答对匹配

### 阶段 4：离线自适应与设置界面 ✅
- **SettingsDialog**：网络开关、性能模式、心跳间隔、皮肤选择
- 自适应降级：技能调用前检查 manifest 中的 requires_network
- canRunSkill() / skillsRequiringNetwork() 方法

### 阶段 5：打包与发布 ✅
- **package.ps1**：编译 Release → windeployqt → VC++ 运行时 → ZIP 打包
- README.md 更新

### 阶段 6：可选增强 ✅
- **CrashHandler**：qInstallMessageHandler + SetUnhandledExceptionFilter，minidump 生成
- 技能协议支持任何语言（包括 Rust）编写的 exe
- **SkillMarketDialog**：联网浏览/下载技能插件

## 六、技术要点

### 头文件规范
- 所有公共头文件使用前置声明代替 #include
- PlatformDefines.h 作为每个 .cpp 的第一行
- 禁止在头文件中包含 windows.h

### 模块解耦
- 严格分层：Core → UI/Appearance/Voice/Action → Skills
- 层间通过 EventBus 事件通信
- 禁止跨模块直接函数调用

### 技能插件协议
- JSON 行协议：stdin 输入请求，stdout 输出响应
- 单次任务后退出，禁止长连接
- 5 秒超时保护

### 离线优先
- 默认关闭网络
- 所有技能有本地实现
- 自适应降级
